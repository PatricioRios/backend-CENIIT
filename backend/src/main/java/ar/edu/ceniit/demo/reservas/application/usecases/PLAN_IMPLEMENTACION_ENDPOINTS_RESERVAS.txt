1.1. existeReservaInRange()
────────────────────────────
PROPÓSITO: Validar que no exista solapamiento de reservas

LÓGICA DE SOLAPAMIENTO:
Dos reservas se solapan si:
  (nuevaInicio < existenteFin) AND (nuevaFin > existenteInicio)

SQL EQUIVALENTE:
  SELECT COUNT(*) > 0
  FROM reservas_schema.reserva
  WHERE recurso_solicitado_id = ?
    AND estado != 'CANCELADA'
    AND fecha_hora_inicio < ?  -- nuevaFin
    AND fecha_hora_fin > ?     -- nuevaInicio

IMPLEMENTACIÓN:
@Override
public boolean existeReservaInRange(Integer recursoId, 
                                    OffsetDateTime fechaHoraInicio, 
                                    OffsetDateTime fechaHoraFin) {
    Specification<ReservaEntityTable> spec = (root, query, builder) -> {
        Predicate recursoMatch = builder.equal(
            root.get("recursoSolicitadoId"), recursoId);
        
        Predicate noEstaCancelada = builder.notEqual(
            root.get("estado"), EstadoReserva.CANCELADA);
        
        // Lógica de solapamiento:
        // La reserva existente termina DESPUÉS de que empieza la nueva
        Predicate finDespuesDeNuevoInicio = builder.greaterThan(
            root.get("fechaHoraFin"), fechaHoraInicio);
        
        // La reserva existente empieza ANTES de que termine la nueva  
        Predicate inicioAntesDenNuevoFin = builder.lessThan(
            root.get("fechaHoraInicio"), fechaHoraFin);
        
        return builder.and(
            recursoMatch, 
            noEstaCancelada,
            finDespuesDeNuevoInicio,
            inicioAntesDenNuevoFin
        );
    };
    
    return reservaRepository.count(spec) > 0;
}

CASOS DE PRUEBA:
✓ Reserva existente: 10:00-12:00, Nueva: 11:00-13:00 → TRUE (solapa)
✓ Reserva existente: 10:00-12:00, Nueva: 12:00-14:00 → FALSE (no solapa)
✓ Reserva existente: 10:00-12:00, Nueva: 08:00-10:00 → FALSE (no solapa)
✓ Reserva existente: 10:00-12:00, Nueva: 09:00-11:00 → TRUE (solapa)
✓ Reserva cancelada no cuenta


1.2. createReserva()
────────────────────
PROPÓSITO: Crear nueva reserva en estado PENDIENTE

LÓGICA:
1. Mapear Reserva (domain) → ReservaEntityTable (entity)
2. Establecer estado = PENDIENTE (si no viene)
3. Establecer solicitanteId
4. Guardar en BD
5. Mapear ReservaEntityTable → Reserva (domain)
6. Retornar

IMPLEMENTACIÓN:
@Override
public Reserva createReserva(Reserva reserva, Integer solicitanteId) {
    ReservaEntityTable entity = reservaMapper.toEntity(reserva);
    
    // Establecer campos de creación
    entity.setSolicitanteId(solicitanteId);
    entity.setEstado(reserva.getEstado() != null ? 
                     reserva.getEstado() : EstadoReserva.PENDIENTE);
    
    // Guardar en BD
    ReservaEntityTable savedEntity = reservaRepository.save(entity);
    
    // Mapear de vuelta a dominio
    return reservaMapper.toDomain(savedEntity);
}

VALIDACIONES:
- solicitanteId NOT NULL (campo obligatorio en BD)
- recursoSolicitadoId NOT NULL
- fechaHoraInicio y fechaHoraFin NOT NULL
- nombre NOT NULL

EXCEPCIONES POSIBLES:
- DataIntegrityViolationException: Si FK no válida (usuario/recurso no existe)
- ConstraintViolationException: Si campos obligatorios nulos


1.3. updateReserva()
────────────────────
PROPÓSITO: Actualizar estado de reserva (aprobar/cancelar)

LÓGICA ACTUAL DEL USE CASE:
- aprovarReserva() → Crea Reserva parcial con (id, approverId, CONFIRMADA)
- cancelarReserva() → Crea Reserva parcial con (id, cancelerId, CANCELADA)

Solo se actualiza:

  - aprobador_o_cancelador_id

IMPLEMENTACIÓN:
@Override
public Reserva updateReserva(Reserva reserva) {
    // 1. Buscar reserva existente
    ReservaEntityTable existing = reservaRepository.findById(reserva.getId())
        .orElseThrow(() -> new ReservaNotFoundException(
            "Reserva con ID " + reserva.getId() + " no encontrada"));
    
    // 2. Actualizar solo campos necesarios
    if (reserva.getEstado() != null) {
        existing.setEstado(reserva.getEstado());
    }
    
    if (reserva.getAprobadorOCanceladorId() != null) {
        existing.setAprobadorOCanceladorId(reserva.getAprobadorOCanceladorId());
    }
    
    // 3. Guardar cambios
    ReservaEntityTable updated = reservaRepository.save(existing);
    
    // 4. Mapear a dominio
    return reservaMapper.toDomain(updated);
}

VALIDACIONES:
- reservaId debe existir (lanzar ReservaNotFoundException si no)
- Opcionalmente validar transiciones de estado:
  * PENDIENTE → CONFIRMADA (aprobar)
  * PENDIENTE → CANCELADA (cancelar)
  * CONFIRMADA → CANCELADA (cancelar después de aprobar)
  * NO permitir: CANCELADA → CONFIRMADA

EXCEPCIONES:
- ReservaNotFoundException: Si reservaId no existe
- InvalidStateTransitionException: Si cambio de estado no permitido (opcional)

@PostMapping("/{recursoId}/reservas")
@PreAuthorize("isAuthenticated()")
public ResponseEntity<ReservaResponseDTO> createReserva(
        @PathVariable Long recursoId,
        @RequestBody CreateReservaRequestDTO request,
        @AuthenticationPrincipal KeycloakPrincipal principal) {
    
    // Obtener ID del usuario autenticado
    Integer userId = getUserIdFromPrincipal(principal);
    
    // Crear objeto de dominio
    Reserva reserva = new Reserva(
        null, // ID será generado por BD
        request.getNombre(),
        request.getDescripcion(),
        request.getFechaHoraInicio(),
        request.getFechaHoraFin(),
        EstadoReserva.PENDIENTE,
        recursoId.intValue(),
        userId,
        null
    );
    
    // Llamar al caso de uso
    Reserva created = reservasUseCases.createReserva(reserva, userId);
    
    // Mapear a DTO de respuesta
    ReservaResponseDTO response = reservaDTOMapper.toDTO(created);
    
    return ResponseEntity.status(HttpStatus.CREATED).body(response);
}

VALIDACIONES:
- @Valid en request body
- fechaHoraInicio < fechaHoraFin
- fechaHoraInicio > ahora (no crear reservas en el pasado)
- nombre: @NotBlank, max 200 caracteres

package ar.edu.ceniit.demo.reservas.infraestructure.input.dto;

import jakarta.validation.constraints.*;
import lombok.Data;
import java.time.OffsetDateTime;

@Data
public class CreateReservaRequestDTO {
    
    @NotBlank(message = "El nombre es obligatorio")
    @Size(max = 200, message = "El nombre no puede exceder 200 caracteres")
    private String nombre;
    
    @Size(max = 500, message = "La descripción no puede exceder 500 caracteres")
    private String descripcion;
    
    @NotNull(message = "La fecha de inicio es obligatoria")
    @Future(message = "La fecha de inicio debe ser futura")
    private OffsetDateTime fechaHoraInicio;
    
    @NotNull(message = "La fecha de fin es obligatoria")
    private OffsetDateTime fechaHoraFin;
    
    @AssertTrue(message = "La fecha de inicio debe ser anterior a la fecha de fin")
    public boolean isFechaInicioAntesDeFin() {
        if (fechaHoraInicio == null || fechaHoraFin == null) {
            return true; // Dejamos que @NotNull maneje los nulos
        }
        return fechaHoraInicio.isBefore(fechaHoraFin);
    }
}

@ExceptionHandler(RecursoYaReservado.class)
public ResponseEntity<ErrorResponse> handleRecursoYaReservado(
        RecursoYaReservado ex) {
    ErrorResponse error = new ErrorResponse(
        "RECURSO_YA_RESERVADO",
        ex.getMessage(),
        HttpStatus.CONFLICT.value()
    );
    return ResponseEntity.status(HttpStatus.CONFLICT).body(error);
}

@ExceptionHandler(ReservaNotFoundException.class)
public ResponseEntity<ErrorResponse> handleReservaNotFound(
        ReservaNotFoundException ex) {
    ErrorResponse error = new ErrorResponse(
        "RESERVA_NOT_FOUND",
        ex.getMessage(),
        HttpStatus.NOT_FOUND.value()
    );
    return ResponseEntity.status(HttpStatus.NOT_FOUND).body(error);
}

@ExceptionHandler(MethodArgumentNotValidException.class)
public ResponseEntity<ErrorResponse> handleValidationErrors(
        MethodArgumentNotValidException ex) {
    Map<String, String> errors = ex.getBindingResult()
        .getFieldErrors()
        .stream()
        .collect(Collectors.toMap(
            FieldError::getField,
            FieldError::getDefaultMessage
        ));
    
    ErrorResponse error = new ErrorResponse(
        "VALIDATION_ERROR",
        "Errores de validación",
        HttpStatus.BAD_REQUEST.value(),
        errors
    );
    return ResponseEntity.badRequest().body(error);
}
